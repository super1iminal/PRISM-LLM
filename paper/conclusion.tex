\section{Conclusion}
\label{sec:conclusion}

In this paper, we proposed a verifier-guided framework for adaptation through controller reuse and generation across families of stochastic environments.
An LLM wrote generalized rule lists and refined them with quantitative feedback from probabilistic model checking, and an adaptation manager retained or selected a rule list only where it was certified on the instance at hand, invoking generation where none was.
We evaluated controller reuse on held-out instances of grid-world navigation, Pac-Man and Mars Exploration Rovers.
The generated rule lists certified more held-out grid-world instances than the baselines and matched the best baseline on the other two domains\todo{keep in step with the abstract once the evaluation is final}.

As future work, we plan to evaluate the extension of the library over longer sequences of instances than our sequential study covers.
We also aim to let the LLM write the vocabulary itself, since our rule lists currently rely on constants and features that each domain provides.
