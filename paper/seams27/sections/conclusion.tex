\section{Conclusion}\label{sec:conclusion}

An LLM can write one short, readable controller for a family of MDPs, and a probabilistic model checker can both
refine it and certify it on every instance the system will meet. The division of labour matters: prompting changes
little, while letting the verifier resolve the choices the LLM leaves open is what makes the rules transfer.
