A self-adaptive system rarely faces one fixed environment: layouts, sizes and mission lengths change, and
synthesising and verifying a new controller for each variant at run time is costly. We ask whether a large language
model (LLM) can write \emph{one} readable controller for a whole family of Markov decision processes (MDPs) that a
probabilistic model checker then certifies, instance by instance, including instances larger than any seen in
training. The LLM writes an ordered list of rules over a domain vocabulary of features and instance constants; a
loop verifies the rules on a few small training instances with PRISM and feeds the results back. The verifier also
refines the rules itself: where a rule allows several actions, it resolves the choice into the action order that
does best on the training instances, so that the LLM is shown how the policy that will actually be deployed fails.
The frozen rules are then certified on held-out instances against several probabilistic requirements at once.
On gridworld families and on the Pac-Man benchmark, rules written by Claude Haiku~5.5 for about one cent per
training set certify \todo{X} of held-out instances, against \todo{Y} for decision trees learned from optimal
strategies (as in 1--2--3--Go!), \todo{Z} for PPO and \todo{W} for a search over the same rule language. Prompting
variants change little; resolving the LLM's choices by verification is what makes the rules transfer.
